### Step 2: AI Insight

**What you see:** The dashboard shows proactive insights like:
- ⚠️ "Khoản vay chiếm 55.6% thu nhập — nên ưu tiên trả nợ"
- 💡 "Nếu tăng tiết kiệm thêm 3.0M VND/tháng, bạn có thể rút ngắn 621 tháng để đạt mục tiêu"
- ✅ "Bạn đang giữ được 40.0% thu nhập mỗi tháng"

These are **deterministic** (generated by the insight engine, not the LLM).

### Step 3: Ask AI — "Nếu năm sau tôi có con thì sao?"

**Action:** Navigate to AI Coach (`/coach`) and ask:
```
Nếu năm sau tôi có con thì sao?
```

**What happens behind the scenes:**
1. **Supervisor** classifies intent → `LIFE_EVENT_QUERY`
2. **Agent selection** → `scenario` agent
3. **Tool filtering** → `simulateLifeEvent`, `calculateGoalProjection`, `getFinancialProfile`, `getFinancialInsights`
4. **Mock LLM** detects life event keywords → calls `simulateLifeEvent`
5. **Financial Engine** runs `simulateLifeEvent(profile, HAVE_CHILD)`
6. **Response generation** formats before/after comparison

**What you see:**

```
Trước:
- Thu nhập: 30.0M VND/tháng
- Chi phí: 18.0M VND/tháng
- Tiết kiệm: 12.0M VND/tháng
- Điểm sức khỏe: 62/100

Sau:
- Thu nhập: 30.0M VND/tháng
- Chi phí: 23.0M VND/tháng
- Tiết kiệm: 7.0M VND/tháng
- Điểm sức khỏe: 49/100

Tác động:
- Thay đổi tiết kiệm: -5.0M VND/tháng
- Thay đổi sức khỏe: -13 điểm
- Thay đổi thời gian mục tiêu: +0 tháng

⚠️ Sự kiện này làm giảm khả năng tiết kiệm.
Bạn nên cân nhắc điều chỉnh chi phí hoặc thời gian mục tiêu.
```

**Tool calls visible:** 3 tools called (getFinancialProfile, simulateLifeEvent, getFinancialInsights)

## API Demo (curl)

```bash
# Health check
curl http://localhost:8080/health

# Demo profile
curl http://localhost:8080/api/profile/demo

# Dashboard (all data)
curl http://localhost:8080/api/dashboard/demo-user-minhanh

# Life event simulation
curl -X POST http://localhost:8080/api/life-events/simulate \
  -H "Content-Type: application/json" \
  -d '{"userId":"demo-user-minhanh","type":"HAVE_CHILD","assumptions":{"monthlyChildCost":5000000,"oneTimeCost":20000000,"incomeReductionMonths":3,"incomeReductionPercent":30}}'

# AI chat with life event
curl -X POST http://localhost:8080/api/ai/chat \
  -H "Content-Type: application/json" \
  -d '{"userId":"demo-user-minhanh","message":"Neu nam sau toi co con thi sao?"}'

# Affordability check
curl -X POST http://localhost:8080/api/life-events/affordability \
  -H "Content-Type: application/json" \
  -d '{"userId":"demo-user-minhanh","price":3000000000,"downPayment":600000000,"interestRate":8,"loanTermMonths":300}'
```

## Key Differentiators

1. **Financial calculations by deterministic engine** — LLM never calculates
2. **Multi-agent with intent routing** — supervisor classifies and routes
3. **Life event simulator** — before/after comparison with editable assumptions
4. **Explainable health score** — click any dimension for drill-down
5. **Proactive insights** — deterministic, not hallucinated
6. **Guardrails** — no guaranteed returns, hedging language, prompt injection protection
7. **Tool calling transparency** — users see which tools were called
